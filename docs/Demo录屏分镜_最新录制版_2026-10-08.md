## 录制前准备

- 双击桌面 `启动混合检索Demo.bat`，以启动窗口输出的本次端口为准；不要默认使用旧端口。
- 预热查询：规则讲解不清晰、重复提问、玩家觉得 DM 没有耐心。
- 浏览器缩放 90% 至 100%，隐藏无关标签页和桌面通知。
- 当前固化演示数据：5 个 DM、17 个场次、18 条玩家评价、18 条 AI 分析、5 个改进任务；首页加载后会自动显示近30天聚合结果。
- 只展示已验证内容：模拟门店数据、模拟知识库、7/7 模拟检索评测、2/2 隔离端到端测试。
- 录屏中不要展示 API Key、配置文件密钥或控制台密钥。

## 剪辑与表达规则

- 页面操作保持连续，单个结果至少停留 2.5 秒，确保 HR 能读到 method、权重和引用。
- 混合检索成功时必须完整显示 `hybrid:bm25=0.60,embedding=0.40`；不要用裁剪或旁白替代。
- 录屏中不要说“提升了门店收益”“已经生产部署”“真实客户验证”，因为当前证据不支持这些结论。
- 统一把项目称为“个人 Demo / 模拟门店数据 / 模拟知识库验证”。
- 若现场网络不稳定，提前预热缓存；如果仍失败，应诚实展示 `bm25_only` 降级状态，不要剪辑成混合检索成功。
