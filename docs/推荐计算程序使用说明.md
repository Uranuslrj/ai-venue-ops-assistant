# 推荐计算程序使用说明

对应程序：`recommend_dm.py`

## 1. 运行环境

需要 Python 3.9 或更高版本。程序只使用 Python 标准库，不需要额外安装第三方包。

## 2. 文件位置

程序默认从自身所在目录读取：

```text
dm_profile_template.csv
player_requirement_weights.csv
session_records.csv
```

因此这几个文件应与 `recommend_dm.py` 放在同一个文件夹。

## 3. 运行命令

在 `work` 文件夹中打开终端，运行：

```bash
python recommend_dm.py --request-id REQ001
```

其中 `REQ001` 是玩家需求表中的 `request_id`。

也可以运行其他需求：

```bash
python recommend_dm.py --request-id REQ002
python recommend_dm.py --request-id REQ003
```

## 4. 输出文件

程序会生成：

```text
recommendation_records_generated.csv
```

这张表会记录：

- 每个DM是否通过硬性筛选；
- 六维匹配分；
- 评分可信度；
- 最终推荐分；
- 排名；
- 推荐理由；
- 店长是否确认。

## 5. 程序处理顺序

```text
读取玩家需求
→ 找到对应场次
→ 检查DM当前是否可用
→ 检查日期是否可出勤
→ 检查时间段是否可用
→ 检查是否能主持该剧本
→ 检查是否存在场次冲突
→ 计算六维匹配分
→ 计算评分可信度
→ 计算最终推荐分
→ 输出排序结果
```

## 6. 面试时如何介绍

可以这样说：

> 我把推荐逻辑拆成硬性筛选和软性排序两层。系统先排除当前不可用、时间不匹配、不会主持该剧本或存在排班冲突的DM，再使用玩家六维需求权重与DM六维能力评分计算匹配分，最后通过评价数量计算可信度，输出带有推荐理由的候选排序。店长仍然保留最终确认权。

## 7. 当前版本边界

当前程序使用 `dm_profile_template.csv` 中已有的六维分数作为“当前刷新评分”输入。下一步如果要完全自动化，还可以增加：

- 从 `feedback_records.csv` 自动计算六维刷新评分；
- 从 `ai_feedback_results.csv` 自动汇总近期同类问题；
- 将店长确认结果写回场次表；
- 接入网页界面和数据库。
