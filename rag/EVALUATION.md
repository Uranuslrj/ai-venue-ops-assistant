# RAG MVP 评测说明与失败案例

日期：2026-09-30

## 当前评测集

`evaluation_cases.json` 包含 7 个固定案例，覆盖规则讲解、节奏、开场互动、无关反馈、正向反馈、笼统反馈和沉浸问题。评测检查期望来源、禁止来源、依据不足降级，以及正向反馈不生成负向改进任务。

当前本地运行结果：7/7 通过。该结果仅代表这 7 条小型模拟用例通过，不代表生产准确率、召回率或真实业务效果。

## 失败案例与修复记录

1. 初版中文字符 n-gram 让“空调太冷”与 DM 规则知识误召回。修复：领域词项切分、无关领域保护、覆盖门槛；添加 EVAL-004 回归。
2. 初版把 BM25 分数称为置信度，容易被误读为概率。修复：改为“相关度分”，明确只用于排序。
3. 正向反馈可能被当成负向纠偏。修复：正向反馈分流，不生成改进任务；添加 EVAL-005。
4. “体验一般”可能误命中服务知识。修复：笼统反馈降级要求补充信息；添加 EVAL-006。

## 评测边界

评测集由项目作者编写，规模较小且与规则文档同源，存在过拟合风险。后续应加入业务人员独立编写的盲测集、同义表达、拼写错误、混合正负反馈和不同剧本类型样例，并分别报告来源召回、无依据拒答和误建议情况。
